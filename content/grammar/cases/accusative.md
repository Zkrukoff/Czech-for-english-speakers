## What it's used for

The accusative answers **koho? co?** (whom? what?). It's the case of the **direct object**, the thing the action is done to.

1. **Direct object**:
   - *Dám si **kávu**.* I'll have a coffee.
   - *Mám **sestru**.* I have a sister.
   - *Vidím **Petra**.* I can see Petr.
2. **Time "for" and "every"**:
   - *Byl jsem tam **celý týden**.* I was there the whole week.
   - *Cvičím **každý den**.* I exercise every day.
   - *v **pondělí**, v **sobotu*** on Monday, on Saturday
3. **After verbs with a fixed preposition**: *čekat na* (wait for), *dívat se na* (look at), *těšit se na* (look forward to), *myslet na* (think about), *děkovat za* (thank for):
   - *Čekám **na autobus**.* I'm waiting for the bus.
   - *Těším se **na víkend**.* I'm looking forward to the weekend.

## Prepositions that take the accusative

| Preposition | Meaning | Example |
|---|---|---|
| **na** (+ motion or purpose) | to, onto; for (a time) | *Jdu **na poštu**. Jedu tam **na týden**.* |
| **pro** | for (someone/something); to fetch | *dárek **pro mámu**. Jdu **pro rohlíky**.* |
| **za** (time) | in (time from now) | *Přijdu **za hodinu**.* I'll come in an hour. |
| **za** (exchange) | for | *Děkuji **za pomoc**.* |
| **přes** | across, through; via | ***přes ulici**, **přes Vídeň*** |
| **o** | against; (ask) for | *Prosím **o pomoc**.* |
| **v** (days, belief) | on (a day); in | ***v pondělí**, věřit **v Boha*** |
| **mezi, nad, pod, před, za** (+ motion) | between, above, under, in front of, behind | *Dej to **pod stůl**.* Put it under the table. |

### Movement vs. location

Several prepositions take the **accusative for movement** and a different case for location. This is one of the most important patterns in Czech:

| Where to? (accusative) | Where? (locative / instrumental) |
|---|---|
| Jdu **na poštu**. | Jsem **na poště**. (locative) |
| Dej to **na stůl**. | Je to **na stole**. (locative) |
| Polož to **pod stůl**. | Je to **pod stolem**. (instrumental) |
| Sedni si **před televizi**. | Sedím **před televizí**. (instrumental) |

English uses "to/onto" vs "on" for the same idea; Czech changes the case instead.

## Compared with English

English shows the object by word order and with *him, her, me, us, them*. Czech marks every object noun. The good news: for many nouns the accusative looks the same as the nominative:

- **Masculine inanimate** and **neuter**: no change. *Mám čas. Dám si pivo.*
- **Feminine -a → -u**: *káva → kávu, voda → vodu, sestra → sestru*.
- **Feminine -e/consonant**: *-e* → *-i* (*růže → růži*), consonant: no change (*kost*).
- **Masculine animate** = genitive: *pán → pána, Petr → Petra, pes → psa*.

## Common mistakes

- ***Dám si káva*** → ***Dám si kávu.*** Feminine -a nouns always change.
- ***Mám bratr*** → ***Mám bratra.*** Masculine animate nouns (people and animals) take -a, like the genitive.
- ***Mám kávu*** **vs** ***Mám čaj***: don't over-apply *-u* to masculine nouns. *Čaj* stays *čaj*.
- ***Jsem na poštu*** → ***Jsem na poště.*** Use the accusative only for **movement** (*jdu na poštu*); for being somewhere use the locative.
- **Adjectives agree too**: *Dám si **černou** kávu* (černá → černou), *Mám **velkého** psa*.
