## Three forms

| Form | Used for | Example (počkat) |
|---|---|---|
| **ty** | one person you know well | ***Počkej!*** Wait! |
| **my** | "let's" | ***Počkejme!*** Let's wait! |
| **vy** | several people, or anyone you say *vy* to | ***Počkejte!*** Wait! |

## How to form it

Start from the **oni** (3rd person plural) form and drop the ending:

| oni form | ty | vy | |
|---|---|---|---|
| dělaj-í | **dělej** | **dělejte** | -ají → -ej |
| píš-ou | **piš** | **pište** | vowel shortens |
| čt-ou | **čti** | **čtěte** | after two consonants: -i / -ěte |
| mluv-í | **mluv** | **mluvte** | |
| kupuj-í | **kupuj** | **kupujte** | |
| sedn-ou | **sedni** | **sedněte** | |

The *my* form adds **-me** to the *ty* form (*dělejme, pišme*), or **-eme/-ěme** after -i (*čtěme, sedněme*).

### Irregular imperatives

| Verb | ty | vy |
|---|---|---|
| být | **buď** | **buďte** |
| mít | **měj** | **mějte** |
| jíst | **jez** | **jezte** |
| jít | **jdi** (come: **pojď**) | **jděte** (**pojďte**) |
| vědět | **věz** | **vězte** |
| vzít | **vezmi** | **vezměte** |

*Pojď / pojďte* (come!) and *pojďme* (let's go!) are used all the time.

## Which aspect?

- **Positive commands → usually perfective** (do this one thing): ***Zavři** okno. **Zavolej** mi. **Sedněte** si.*
- **Negative commands → usually imperfective**: ***Nezavírej** okno. **Nevolej** mi. **Neboj** se.*

Positive imperfective commands are used for general advice or to urge someone to start or continue: ***Čtěte** nahlas, prosím.* (Read aloud, please.) ***Jez**, než to vystydne.* (Eat, before it gets cold.)

## Being polite

A bare imperative can sound blunt to strangers. Soften it with **prosím** or use a question:

- ***Dejte** mi **prosím** jeden lístek.* Give me one ticket, please.
- ***Mohl byste** mi pomoct?* Could you help me? (a man) / ***Mohla byste**…* (a woman)

## Common mistakes

- ***Ne zavři okno*** → ***Nezavírej okno.*** Write *ne-* together with the verb and use the imperfective.
- **Using *ty* forms with strangers**: say ***Počkejte***, not *Počkej*, to a shop assistant.
- ***Pojď se!*** → ***Pojď!*** *Jít* isn't reflexive.
