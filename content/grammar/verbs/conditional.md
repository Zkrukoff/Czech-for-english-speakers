## How to form it

The conditional uses the same **l-participle** as the [past tense](/verbs/past), plus a special form of *být*:

| | singular | plural |
|---|---|---|
| 1st | chtěl / chtěla **bych** | chtěli / chtěly **bychom** |
| 2nd | chtěl / chtěla **bys** | chtěli / chtěly **byste** |
| 3rd | chtěl / chtěla **by** | chtěli / chtěly **by** |

Like *jsem*, these forms go in the **second position**: ***Chtěl bych** kávu.* / *Já **bych** chtěl kávu.*

More on where these little words go: [Word order and the little words](/grammar/word-order).

> **Heard on the street:** ***bysme*** instead of *bychom*: *Mohli bysme jít ven.* Very common, but write *bychom*.

## Polite requests

This is the most important use for beginners:

- ***Chtěl / Chtěla bych** jeden lístek do Brna.* I'd like one ticket to Brno.
- ***Mohl / Mohla byste** mi pomoct?* Could you help me?
- ***Dal / Dala bych si** pivo.* I'd have a beer.

## "Would" in general

- *To **by bylo** skvělé.* That would be great.
- *Kam **bys** chtěl jet?* Where would you like to go?

## "If" sentences: kdyby

For imaginary or unlikely conditions, use ***kdyby***. It also takes the person endings:

| | |
|---|---|
| kdy**bych** | kdy**bychom** |
| kdy**bys** | kdy**byste** |
| kdy**by** | kdy**by** |

- ***Kdybych měl** čas, **šel bych** do kina.* If I had time, I'd go to the cinema.
- ***Kdybys** chtěla, **mohli bychom** jít spolu.* If you wanted, we could go together.

For real, likely conditions use ***když*** or ***jestli*** with the normal tense: ***Když** bude pršet, zůstaneme doma.* If it rains, we'll stay at home.

## aby: "so that", "to"

*aby* (with the same endings) introduces purpose or a wish:

- *Řekl mi, **abych** přišel.* He told me to come.
- *Učím se česky, **abych** rozuměl lidem.* I'm learning Czech so that I can understand people.

## Common mistakes

- ***Já bych chci*** → ***Já bych chtěl.*** Use the l-participle, not the present.
- ***Kdyby jsem*** → ***Kdybych.*** It's one word with the ending built in.
- ***Chtěl bych*** **said by a woman** → ***Chtěla bych.*** The participle agrees with the speaker.
