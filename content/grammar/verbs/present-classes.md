## One ending per person

English verbs barely change: *I work, you work, she work**s***. Czech verbs have a different ending for each person, so the pronoun is usually left out:

- ***Pracuju** v Praze.* I work in Prague. (No need for *já*.)
- ***Mluvíte** anglicky?* Do you speak English?

The endings are almost the same in every verb:

| Person | Pronoun | Ending |
|---|---|---|
| I | já | **-m** or **-u / -i** |
| you (informal) | ty | **-š** |
| he / she / it | on / ona / ono | — (the stem vowel) |
| we | my | **-me** |
| you (plural, polite) | vy | **-te** |
| they | oni | **-jí / -í / -ou** |

What changes from verb to verb is the **vowel before the ending**. That vowel, which you can see in the *on/ona* form, tells you the class.

## The five classes

Czech grammars number the classes by their *on/ona* form. Learn one model verb for each.

### Class 5: -á (dělá)

The easiest and most common class. *Dělat, mít, znát, čekat, volat, dát…*

```verb dělat
```

### Class 4: -í (mluví, prosí)

Also very common: *mluvit, vidět, bydlet, platit, muset, rozumět…* Some verbs in this class have **-ějí** in the *oni* form (*rozumějí, umějí*); in everyday Czech the shorter *-í* is standard too.

```verb mluvit
```

### Class 3: -je (kupuje, pije)

All verbs ending in **-ovat** belong here: *kupovat, pracovat, potřebovat, jmenovat se…*, plus short verbs like *pít, žít*.

```verb kupovat
```

### Class 1: -e (nese, bere, píše)

The *já* form ends in **-u** (sometimes **-i**). The stem often looks different from the infinitive, so learn these verbs with their *já* form: *psát → píšu, číst → čtu, brát → beru*.

```verb psát
```

### Class 2: -ne (začne, sedne)

Verbs with **-ne-** in the present: *začít → začnu, vstát → vstanu, sednout si → sednu si*. Many of these are perfective (see [aspect](/verbs/aspect)), so their "present" forms actually refer to the future.

```verb začít
```

## -u or -i? (píšu / píši, kupuju / kupuji)

In classes 1 and 3, the *já* and *oni* forms have two standard variants: *píšu/píši, píšou/píší, kupuju/kupuji*. The **-u / -ou** forms are what you'll hear in conversation; the **-i / -í** forms sound more formal and are common in writing. Both are correct. This course uses the **-u** forms by default and accepts both in answers.

> **Heard on the street:** in obecná čeština the *-ou* ending spreads further: *kupujou, pracujou*. You'll hear these all the time, but in writing use *kupují, pracují*.

## Negation

Put **ne-** directly in front of the verb, written as one word: *nemluvím, nerozumím, nemám*. Czech also uses double negatives: *Nikdo **ne**přišel.* (Nobody came.) *Nic **ne**chci.* (I don't want anything.)

## Common mistakes

- **Adding the pronoun every time.** *Já jsem… já mám… já chci…* is grammatical but sounds heavy. Use *já* only for emphasis or contrast.
- **Guessing class-1 forms from the infinitive.** *čístu, psám* don't exist: learn *čtu, píšu*.
- **3rd person plural.** *oni mluví* (not *mluvějí*), *oni dělají*, *oni píšou*.
