## Calling someone by name: the vocative

When you speak **to** someone, their name and title change. This form is the **vocative** (5. pád). Leaving it out (*Ahoj, Petr!*) is one of the most noticeable beginner mistakes.

| Name / title | Speaking to them |
|---|---|
| Jan**a** | Ahoj, Jan**o**! |
| Petr | Ahoj, Pet**ře**! |
| Pavel | Ahoj, Pav**le**! |
| Tomáš | Ahoj, Tomáš**i**! |
| Marek | Ahoj, Mar**ku**! |
| pan Novák | Dobrý den, pan**e** Novák**u**! |
| pan doktor | Dobrý den, pan**e** doktor**e**! |
| paní Nováková | Dobrý den, paní Nováková! (no change) |
| máma / táta | mam**i**, tat**i** |

## The rules in short

- Feminine names in **-a → -o**: *Jana → Jano, Eva → Evo*
- Masculine names in a hard consonant **+ -e**: *Pavel → Pavle, Karel → Karle*
  - **-r** after a consonant **→ -ře**: *Petr → Petře*
  - **-k, -h, -ch → + -u**: *Marek → Marku, Novák → Nováku*
- Masculine names in a soft consonant (š, ž, č, ř, j) **+ -i**: *Tomáš → Tomáši, Ondřej → Ondřeji*
- Names ending in **-e, -i** don't change: *Lucie, Jiří, Marie*
- **paní** and surnames in **-ová** never change

With titles, **every word** changes: *pane doktore, pane Nováku*.
